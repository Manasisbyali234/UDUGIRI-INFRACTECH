# Udugiri Infratech Website

A professional React-based website for Udugiri Infratech, showcasing infrastructure and technology services.

## Features

- **Home Page**: Company introduction, strengths, and value proposition
- **About Us**: Company background, vision, mission, and core values
- **Services**: Detailed information about Surveying, GIS, Infrastructure Engineering, and Software Development services
- **Projects**: Project portfolio and execution capabilities
- **Enquiry**: Professional contact form for client inquiries
- **Careers**: Job opportunities and company culture information
- **Contact**: Complete contact information and communication channels

## Technology Stack

- React 18.2.0
- React Router DOM 6.20.0
- CSS3 with responsive design
- Modern component-based architecture

## Installation

1. Navigate to the project directory:
```bash
cd oneness-infratech
```

2. Install dependencies:
```bash
npm install
```

## Running the Application

Start the development server:
```bash
npm start
```

The application will open in your browser at `http://localhost:3000`

## Building for Production

Create an optimized production build:
```bash
npm run build
```

The build files will be generated in the `build` folder.

## Customization

To customize the website content:

1. **Contact Information**: Update email addresses and phone numbers in `Footer.js` and `Contact.js`
2. **Company Address**: Add the actual address in `Contact.js`
3. **Colors**: Modify the color scheme in `App.css`
4. **Content**: Edit the text content in respective page components
